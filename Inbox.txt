- Retrieve
    ✅ Empty cache return empty
    ✅ Empty cache twice returns empty (no side-effects)
    ✅ Non-Empty cache returns data
    ✅ Non-Empty cache twice returns same data (no side-effects)
    ✅ Error returns error (if applicable, e.g., invalid data)
    - Error twice returns same error (if applicable, e.g., invalid data)

- Insert
    ✅ Insert into empty cache store data
    - Insert non-empty cache overrides previous data with new data
    - Error case (if applicable, e.g., no write permission)

- Delete
    - Empty cache does nothing (cache stays empty and does not fail)
    - Non-Empty cache leave cache empty
    - Error case (if applicable, e.g., no delete permisson)

- Side-effects must run serially to avoid race-conditions
